# AGENTS.md — Reglas de proyecto para Codex y Antigravity

## Misión del proyecto
Desarrollo ágil de prototipos y herramientas operativas mediante Vibe Coding supervisado.

## Principios operativos
1. **Preservar el estado funcional:** Cada cambio debe dejar la aplicación en un estado ejecutable sin errores en consola.
2. **Inspección previa:** No modificar archivos sin haber revisado previamente el contexto y los tipos definidos.
3. **Manejo de dependencias:** Usar librerías estándar y estables. Evitar instalar paquetes experimentales sin consultar al usuario.
4. **Validación visual y funcional:** Acompañar cada entrega de código con instrucciones concretas para que el usuario pueda verificar el resultado visualmente en su navegador local.
